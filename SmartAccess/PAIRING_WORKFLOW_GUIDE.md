```
│           "in_cooldown": false
```

```
│      │

│      │  WHERE binding_id = 1

│      ├─ UPDATE bluetooth_bindings
│      │  SET is_paired = false
│      │  WHERE id = 1
│      │
│      └─→ {
│           "success": true,
│           "message": "Pairing record deleted"
│         }
│
├─ 前端刷新:
│  设备状态变为 🔓 未配对
│
└─→ 完成 ✅
    (设备现在使用MAC识别模式)
```

## 5️⃣ 异常处理流程

### 情况1: 配对超时

```
用户点击配对 → 倒计时开始
                   │
                   ├─ 30秒...
                   ├─ 29秒...
                   ├─ ...
                   ├─ 1秒...
                   │
                   ▼
           配对未完成 (未确认数字)
                   │
                   ▼
           配对模式关闭
                   │
                   ▼
           前端显示: "⏱️  配对超时，请重试"
                   │
                   ▼
           按钮恢复可用
           用户可重新开始配对
```

### 情况2: IRK识别失败 (降级到MAC)

```
上报数据:
{
  "device_irk": "invalid_irk_value",
  "bt_mac": "AA:BB:CC:DD:EE:FF"
}
      │
      ▼
后端验证:
  1. 查询 device_irk → 未找到 ❌
  2. 降级到 MAC 识别 → 找到 ✅
     
返回: {
  "allow": true,
  "method": "mac_fallback",
  "user_id": 1
}
```

### 情况3: 完全陌生设备

```
未配对且未绑定设备靠近
      │
      ▼
後端验证:
  1. 查询 device_irk → 未找到 ❌
  2. 查询 device_mac → 未找到 ❌
      │
      ▼
返回: {
  "allow": false,
  "message": "Device not recognized"
}
      │
      ▼
ESP32 不提示开门
设备保持上锁
```

## 🔐 安全特性总结

### 识别方式优先级

```
优先级 1 (最快)       优先级 2 (降级)
  IRK识别              MAC识别
   ├─ 速度快            ├─ 容错强
   ├─ 安全高            ├─ 兼容旧设备
   ├─ 不受MAC变化       └─ 无加密密钥
   └─ 需要配对

配对流程
  ├─ Numeric Comparison (6位数字确认)
  │  ├─ 双向验证 (手机+设备都要确认)
  │  ├─ 防中间人攻击
  │  └─ 用户友好
  │
  ├─ 密钥交换
  │  ├─ IRK (Identity Resolving Key)
  │  │  └─ 用于识别已配对设备
  │  │
  │  └─ LTK (Long Term Key)
  │     └─ 用于加密后续通信
  │
  └─ 冷却期保护
     ├─ 3分钟内同设备不重复提示
     ├─ 防止意外多次开门
     └─ 计数器记录所有访问
```

## ✅ 关键指标

| 指标 | 值 | 说明 |
|------|-----|------|
| 配对超时 | 30秒 | 用户必须在此时间内确认 |
| 冷却期 | 3分钟 | 防止重复开门 |
| IRK识别延迟 | < 100ms | 从上报到验证完成 |
| MAC识别延迟 | < 200ms | 降级识别延迟 |
| 最大配对设备数 | 20个 | 每个门禁设备 |
| 配对数据保存位置 | 2处 | 数据库 + ESP32 NVS |
| BLE扫描间隔 | 300ms | 检测频率 |
| 配对密钥长度 | 128位 | IRK/LTK 标准长度 |
