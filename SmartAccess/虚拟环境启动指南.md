## 🔧 配置检查

### 数据库配置 (`.env`)

```ini
DATABASE_URL=mysql+pymysql://root:123456@localhost:3306/smartaccess
```

✅ 数据库已成功连接，所有表已自动检测

### 邮件配置 (`.env`)

⚠️ **重要**: 要使用二维码邮件发送功能，需要配置真实的 SMTP 信息：

```ini
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=你的邮箱@gmail.com
SMTP_PASSWORD=你的应用专用密码
SMTP_FROM_EMAIL=smartaccess@example.com
SMTP_FROM_NAME=SmartAccess系统
```

**Gmail 用户**:
1. 开启两步验证
2. 生成应用专用密码: https://myaccount.google.com/apppasswords
3. 将生成的 16 位密码填入 `SMTP_PASSWORD`

**QQ 邮箱用户**:
```ini
SMTP_SERVER=smtp.qq.com
SMTP_PORT=587
SMTP_USER=你的QQ号@qq.com
SMTP_PASSWORD=授权码（非QQ密码）
```

详细配置请参考: [QRCODE_EMAIL_GUIDE.md](QRCODE_EMAIL_GUIDE.md)

## 🐛 常见问题

### 问题 1: 虚拟环境未激活

**现象**: 运行命令时提示找不到模块

**解决**:
```powershell
.\.venv\Scripts\Activate.ps1
# 或直接使用虚拟环境中的 python
.\.venv\Scripts\python.exe your_script.py
```

### 问题 2: 数据库连接失败

**现象**: 
```
sqlalchemy.exc.OperationalError: (pymysql.err.OperationalError) 
(2003, "Can't connect to MySQL server on 'localhost'")
```

**解决**:
1. 确认 MySQL 服务正在运行
2. 检查 `.env` 中的数据库配置
3. 使用 SQLite 作为备选:
   ```ini
   DATABASE_URL=sqlite:///./smartaccess.db
   ```

### 问题 3: 邮件发送失败

**现象**: 
```
yagmail.error.YagConnectionClosed: Unable to login. 
(535, b'5.7.8 Username and Password not accepted')
```

**解决**:
1. Gmail: 确认已启用两步验证并生成应用专用密码
2. QQ 邮箱: 使用授权码，不是 QQ 密码
3. 检查 `.env` 中 SMTP 配置是否正确

### 问题 4: 端口 8000 被占用

**现象**: 
```
OSError: [WinError 10048] 通常每个套接字地址(协议/网络地址/端口)只允许使用一次
```

**解决**:
```powershell
# 更换端口
.\.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8001
```
