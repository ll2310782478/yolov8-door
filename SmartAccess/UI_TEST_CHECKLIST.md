# SmartAccess UI测试清单

## 🧪 测试步骤

### 1. 启动服务器
```powershell
cd U:\BYSJ\yolov-door\yolov8-door\SmartAccess
.\start_server.bat
```

### 2. 页面访问测试

访问以下页面，检查左侧导航栏是否正常显示：

- [ ] http://localhost:8000/web/dashboard - 仪表盘（应显示图表）
- [ ] http://localhost:8000/web/users - 用户管理
- [ ] http://localhost:8000/web/visitors - 访客管理
- [ ] http://localhost:8000/web/face - 人脸识别
- [ ] http://localhost:8000/web/hardware - 硬件设备
- [ ] http://localhost:8000/web/nfc - NFC管理
- [ ] http://localhost:8000/web/remote-door - 远程开门
- [ ] http://localhost:8000/web/logs - 访问日志

### 3. 导航栏功能测试

每个页面都应该有：

#### 左侧导航栏
- [ ] 紫色渐变背景
- [ ] SmartAccess Logo和标题
- [ ] 折叠/展开按钮（☰）
- [ ] 9个导航链接（带图标和文字）
- [ ] 当前页面链接高亮显示（浅色背景）
- [ ] 鼠标悬停效果

#### 顶部栏
- [ ] 页面标题正确
- [ ] 刷新按钮（🔄）
- [ ] 退出登录按钮

### 4. 交互功能测试

- [ ] 点击折叠按钮，导航栏宽度从260px缩小到70px
- [ ] 折叠后只显示图标，文字隐藏
- [ ] 再次点击折叠按钮，恢复展开
- [ ] 点击导航链接，能正确跳转到对应页面
- [ ] 点击刷新按钮，页面数据刷新
- [ ] 点击退出登录，跳转到登录页面

### 5. 响应式设计测试

- [ ] 浏览器窗口宽度 > 768px：导航栏展开（260px）
- [ ] 浏览器窗口宽度 < 768px：导航栏自动折叠（70px）
- [ ] 移动设备模拟：F12 -> 设备工具栏 -> 测试iPhone/iPad

### 6. 样式一致性检查

#### 配色
- [ ] 主色调：紫色 (#667eea)
- [ ] 导航栏：紫色渐变
- [ ] 按钮：主按钮紫色，成功绿色，危险红色
- [ ] 文字：深灰色 (#1a202c)

#### 布局
- [ ] 导航栏固定在左侧

- [ ] 顶部栏固定在顶部
- [ ] 内容区域有适当内边距
