## 📝 常用 API 端点

### 认证 (Auth)
```
POST   /api/auth/login         登录（获取 Token）
POST   /api/auth/logout        注销
GET    /api/auth/me            获取当前用户信息
```

### 用户管理 (Users)
```
GET    /api/users              获取所有用户
POST   /api/users              创建新用户
GET    /api/users/{id}         获取用户详情
PUT    /api/users/{id}         更新用户信息
DELETE /api/users/{id}         删除用户
```

### 人脸识别 (Face Recognition)
```
POST   /api/users/{id}/faces   上传人脸
GET    /api/users/{id}/faces   获取人脸列表
POST   /api/users/{id}/faces/recognize              实时识别
POST   /api/users/{id}/faces/{face_id}/check-permission  检查权限
```

## 🔐 登录流程

1. **POST /api/auth/login**
   ```json
   {
     "username": "admin",
     "password": "admin@123456"
   }
   ```

2. **获得响应：**
   ```json
   {
     "access_token": "eyJhbGc...",
     "token_type": "bearer",
     "expires_in": 1800
   }
   ```

3. **使用令牌调用 API：**
   ```
   Authorization: Bearer YOUR_ACCESS_TOKEN
   ```

## 🎨 Swagger UI 使用步骤

1. 访问 http://localhost:8000/docs
2. 找到 **Authorize** 按钮（右上角）
3. 输入：`Bearer YOUR_ACCESS_TOKEN`
4. 点击 Authorize 确认
5. 现在可以在界面上直接测试 API

## 📱 curl 命令示例

### 登录
```bash
curl -X POST "http://localhost:8000/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin@123456"}'
```

### 获取用户列表
```bash
curl -X GET "http://localhost:8000/api/users" \
  -H "Authorization: Bearer TOKEN_HERE"
```

### 创建新用户
```bash
curl -X POST "http://localhost:8000/api/users" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer TOKEN_HERE" \
  -d '{
    "username":"user1",
    "password":"pass123",
    "email":"user1@example.com",
    "full_name":"用户一"
  }'
```

## 🐛 问题排查

### 问题：无法连接到数据库
**解决：** 检查 MySQL 是否启动，.env 中的凭证是否正确

### 问题：Token 过期
**解决：** 重新登录获取新 Token

### 问题：找不到人脸识别模型
**解决：** 确保 face_access-v2 模块已正确安装

### 问题：API 返回 401
**解决：** 检查 Authorization 头是否包含有效的 Token
