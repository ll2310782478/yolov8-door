# 🔊 MAX98357 接线指南（DIN/GAIN/SD 版本）

## 📌 脚位对应说明

你的 MAX98357 模块标记可能与标准标记不同。以下是对应关系：

| 你的模块标记 | 标准标记 | ESP32 GPIO | 用途 |
|---|---|---|---|
| **DIN** | DOUT | GPIO 36 | 数字音频数据（从 ESP32 来） |
| **GAIN** | GAIN | - | 增益调节（接 GND 或 3.3V） |
| **SD** | SHUTDOWN | 3.3V | 功放开关（接 3.3V 启用） |
| BCLK | BCLK | GPIO 37 | 比特时钟 |
| LRCK | LRCK | GPIO 35 | 声道时钟 |
| VDD | VDD | 3.3V | 电源 |
| GND | GND | GND | 地线 |
| OUT+ | OUT+ | - | 喇叭正极 |
| OUT- | OUT- | - | 喇叭负极 |

---

## 🔌 完整接线（7 根线）

```
ESP32-S3           MAX98357 模块          喇叭
────────           ──────────            ────
GPIO 37 ────────→ BCLK
GPIO 35 ────────→ LRCK
GPIO 36 ────────→ DIN (数据)
3.3V   ────────→ VDD (电源)
3.3V   ────────→ SD (启用功放)
GND    ────────→ GND ─────────→ 喇叭-
                OUT+ ────────→ 喇叭+
                GAIN ──→ GND (3dB增益)
```

## 📋 逐一接线步骤

### 1️⃣ 音频信号线（3 条）
| 模块脚 | 连接到 | 说明 |
|---|---|---|
| **BCLK** | ESP32 GPIO 37 | 比特时钟 |
| **LRCK** | ESP32 GPIO 35 | 声道时钟 |
| **DIN** | ESP32 GPIO 36 | 数字音频数据输入 |

### 2️⃣ 电源线（2 条）
| 模块脚 | 连接到 | 说明 |
|---|---|---|
| **VDD** | ESP32 3.3V | 功放芯片电源 |
| **GND** | ESP32 GND | 接地（至少接 2 个 GND 脚） |

### 3️⃣ 控制线（2 条）
| 模块脚 | 连接到 | 说明 |
|---|---|---|
| **SD** | ESP32 3.3V | 功放开关（接 3.3V = 启用，接 GND = 关闭） |
| **GAIN** | ESP32 GND | 增益设置（接 GND = 3dB，接 3.3V = 6dB） |

### 4️⃣ 喇叭线（2 条）
| 模块脚 | 连接到 | 说明 |
|---|---|---|
| **OUT+** | 喇叭正极（红线） | 音频输出正 |
| **OUT-** | 喇叭负极（黑线） | 音频输出负 |

## 🔊 固件配置

你的固件中已经配置了正确的 GPIO：

```cpp
#define I2S_BCLK 37   // 比特时钟
#define I2S_LRCK 35   // 声道时钟  
#define I2S_DOUT 36   // 数字输出（对应你的 DIN）
```

**无需改动，直接接线即可！**

## ⚠️ 重要提示

### DIN vs DOUT 的区别

- **从 ESP32 的角度**：GPIO 36 是 **DOUT**（数据输出给功放）
- **从 MAX98357 的角度**：该脚是 **DIN**（数据输入接收音频）

**你的模块标记为 DIN 是正确的！** 这表示 ESP32 将数据**输出**到 MAX98357 的**输入**脚。

### GAIN 脚位

- 接 **GND** = 3dB 增益（较安静）
- 接 **3.3V** = 6dB 增益（较响亮）

根据你的喇叭功率选择：
- **小喇叭** → 接 3.3V（6dB）获得更大音量
- **大喇叭** → 接 GND（3dB）避免失真

### SD 脚位（Shutdown）

- 接 **3.3V** = 功放启用（正常工作）✅
- 接 **GND** = 功放关闭（省电模式）

**推荐接 3.3V！**

## 🧪 测试接线

接好后，固件会在以下时刻播放提示音：
1. **启动时**："嘟"音 → 说明 I2S 初始化成功
2. **NFC 读卡**："滴"音 → 说明音频驱动工作
3. **开门成功**："咔"音 → 说明喇叭连接正确

**如果没声音，检查：**
- DIN → GPIO 36（数字音频数据）
- BCLK → GPIO 37（时钟）
- LRCK → GPIO 35（时钟）
- 这 3 条线必须正确！

## 🆘 常见问题

**Q: DIN 是什么意思？**
A: 数字音频输入端口（Digital IN），从 ESP32 接收音频数据。

**Q: 为什么叫 DIN 不叫 DOUT？**
A: 从 MAX98357 芯片的角度看，这是输入端（IN）。从 ESP32 的角度看，是输出端（OUT）。模块标记用的是芯片视角。

**Q: GAIN 和 SD 不接会怎样？**
A: 
- 不接 GAIN → 使用模块默认增益（通常 3dB）
- 不接 SD → 功放可能无法启动（建议接 3.3V）

**Q: 喇叭接反极性会坏吗？**
A: 不会坏，只是没声音。反过来接就好了。
