# SmartAccess运行说明

## 🚀 如何启动项目

### 方法一：双击运行批处理文件（推荐）

1. 打开文件资源管理器
2. 导航到：`U:\BYSJ\yolov-door\yolov8-door\SmartAccess`
3. 双击运行 `run.bat`
4. 等待看到 "Uvicorn running on http://0.0.0.0:8000"提示
5. 打开浏览器访问：http://localhost:8000/web/auth

### 方法二：手动命令行启动

1. 按`Win+R`，输入 `cmd`，回车
2. 切换到项目目录：
   ```batchfile
   cd /d U:\BYSJ\yolov-door\yolov8-door\SmartAccess
   ```
3. 激活虚拟环境：
   ```batchfile
   .venv\Scripts\activate
   ```
4. 启动服务器：
   ```batchfile
   python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```
5. 看到 "INFO:     Uvicorn running on..."表示启动成功

## 📦 如果需要安装依赖

如果启动时报错说缺少模块，请先安装依赖：

```batchfile
cd /d U:\BYSJ\yolov-door\yolov8-door\SmartAccess
.venv\Scripts\activate
pip install -r requirements.txt
```

## 🔧 常见问题

### 1. 端口 8000 被占用
解决：使用其他端口
```batchfile
python -m uvicorn app.main:app --host 0.0.0.0 --port 8001
```

### 2. 找不到虚拟环境
确保`.venv` 文件夹存在于项目目录下

### 3. 数据库错误
首次运行时会自动创建数据库，如有问题可以删除`smartaccess.db` 重新启动

### 4. 登录后跳转问题
已在所有页面添加认证守卫，未登录会自动跳转到登录页

## 🛑 如何停止服务

- 在命令行窗口按`Ctrl+C`
- 或关闭命令行窗口
